# ecommerce-recommendation-system.# E-Commerce Website 🛒

## 📌 Project Overview

This E-Commerce Website is a full-stack web application developed as a Minor Project for the B.Tech (CSE) program. The platform enables users to browse products, manage carts, place orders, and make secure online payments, while admins manage products, users, and orders.

The project is built using **Django** for the backend, **HTML, CSS, JavaScript & Bootstrap** for the frontend, and **Relational Databases (MySQL/PostgreSQL)** for data management.

---

## 🎯 Objectives

* Provide a **user-friendly and responsive** shopping experience
* Enable **secure authentication & transactions**
* Implement **product, cart, and order management**
* Support **multiple payment methods**
* Offer an **admin dashboard** for site management

---

## 🚀 Features

* 👤 User Registration & Login
* 🛍️ Product Listing & Categorization
* 🔍 Search & Filter Products
* 🛒 Shopping Cart Management
* 💳 Secure Payments
* ⭐ Product Reviews & Ratings
* 📦 Order Tracking
* 🛠️ Admin Panel (Products, Orders, Users)

## ⚙️ Installation & Setup

1. **Clone the repository**

```bash
git clone https://github.com/DevMaheshBatta/your-repo-name.git
```

2. **Navigate to the project directory**

```bash
cd Ecommerce-Website
```

3. **Create & activate virtual environment**

```bash
python -m venv venv
venv\\Scripts\\activate
```

4. **Install dependencies**

```bash
pip install -r requirements.txt
```

5. **Apply migrations**

```bash
python manage.py migrate
```

6. **Run the server**

```bash
python manage.py runserver
```

7. Open browser:

```
http://127.0.0.1:8000/
```
